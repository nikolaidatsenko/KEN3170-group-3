## How to navigate this repo

- Each `assignmentN/` folder is self-contained: notebook, README, and any supporting files needed to run it.
- Start with that folder's own `README.md` for assignment-specific context, task description, and findings.
- Final submissions are marked with tagged GitHub Releases (e.g. `assignment-1-submission`) — see the [Releases page](../../releases) for graded versions.
